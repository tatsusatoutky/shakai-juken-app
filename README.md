# かもしかカッシーの社会アプリ

高校受験（公立高校の標準レベル〜都立上位校・自校作成校レベル）を対象に、歴史・地理・公民をSRS（間隔反復）で学習するアプリです。マスコットは[eigo-juken-app](../eigo-juken-app)と同じ、かもしかの「カッシー」。

詳しい仕様は [SPEC.md](SPEC.md) を参照してください。

## 現在の実装状況（Phase 1〜3相当・一括実装）

- 用語（歴史・地理・公民）と一問一答・穴埋め・並べ替え問題のSRS基本機能。用語は「用語→意味」「意味→用語」「文中の空所補充」の4択と、「読み方をひらがなで入力」の4パターンで出題し、正解/不正解と自己評価（もう一度／普通／簡単）に応じて次の復習タイミングを自動調整します。
- テストモード（全範囲／歴史／地理／公民／苦手単元／自由選択の6パターン、10・20・30問、結果一覧と解説、間違えた問題は自動的にSRSの復習対象に）。
- 統計画面（用語・一問一答別の習得率、歴史・地理・公民の分野別到達度、basic/advancedのレベル別到達度、一問一答の単元別正答率、テスト結果履歴）。
- PWA化（manifest.json＋Service Workerでオフライン対応、ホーム画面に追加可能）。設定画面（目標受験日・JSONバックアップの書き出し/読み込み・全データ削除）。目標受験日から逆算した復習ペース調整と、本番30日前からの「直前対策：総復習テスト」。
- コンテンツ量：用語300（歴史100／地理100／公民100、basic 180／advanced 120）、一問一答150（歴史50／地理50／公民50、basic 90／advanced 60）。`advanced`は都立上位校・自校作成校（日比谷・西・国立等）を意識した、複数知識の関連付けや資料読み取りを要する応用問題を含みます。歴史の年代整序問題は、選択肢を順序文字列にした4択として出題されます。
- 最終的な分量目安（用語 約900・一問一答 約450）の約1/3まで到達。さらなる増量は今後の課題として持ち越しです（詳細は[SPEC.md](SPEC.md)12章）。

## 特徴

- 用語・一問一答は、高校入試で一般的に扱われる範囲・傾向を踏まえて独自に精選（`data/terms.json` / `data/questions.json`）。特定の市販教材・問題集からの転記はしていません
- SM-2簡易版のSRSで、忘れかけた頃に復習が来る仕組み（[eigo-juken-app](../eigo-juken-app)と共通のアルゴリズム）
- データは端末内のブラウザ（localStorage）にのみ保存。サーバー送信・ログインなし
- 素のHTML/CSS/JavaScript（ビルド不要、フレームワークなし）

## ローカルで動作確認する方法

ビルド不要の素のHTML/CSS/JavaScriptです。フォルダ内で簡易サーバーを立てて開くだけで動作確認できます（`fetch`でJSONを読み込むため、`index.html`を直接ダブルクリックして開くのではなく、必ずローカルサーバー経由で開いてください）。

```bash
# このフォルダの中で実行
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

iPhoneで確認する場合は、同じWi-Fiに繋いだ状態でPCのIPアドレス（例：`http://192.168.x.x:8000`）にSafariからアクセスしてください。

## 開発メモ

- `index.html` … アプリのHTML本体（ホーム／学習セッション／サマリー／テスト設定・結果／統計／設定の各画面をJSで切り替え）
- `css/style.css` … 見た目（[eigo-juken-app](../eigo-juken-app)と共通デザイン）
- `js/config.js` … 定数（復習間隔ステップ、ストレージキー名など）
- `js/storage.js` … SRS進捗・設定・テスト結果の保存・読み込み（localStorage）
- `js/srs.js` … SM-2簡易版のスケジューリングロジック（復習間隔の計算、習得済み判定、学習ストリーク、目標受験日による間隔キャップ）
- `js/quiz.js` … 出題パターンの生成（entryType＝term/questionごとに出題形式を出し分け、4択の選択肢作成・穴埋めの空所化を行う）
- `js/test.js` … テストモードの出題プール選定（歴史／地理／公民／苦手単元／自由選択）とテスト結果の保存
- `js/stats.js` … 統計画面向けの集計（種別・分野別・レベル別習得率、一問一答の単元別正答率）
- `js/backup.js` … 学習データのJSONバックアップ書き出し／読み込み
- `js/app.js` … 画面制御・全体のロジック（データ読み込み、SRS学習セッション・テストモード・統計・設定画面の進行、採点）
- `data/terms.json` … 用語データ（300件：歴史100／地理100／公民100）
- `data/questions.json` … 一問一答・穴埋め・並べ替え問題データ（150問：歴史50／地理50／公民50）
- `manifest.json` / `service-worker.js` … PWA化・オフライン対応の設定
- `icons/` … アプリアイコン（かもしかのカッシー、[eigo-juken-app](../eigo-juken-app)と共用）

## データのバックアップについて

設定画面（ホーム画面下部の「設定」）からJSONファイルとして書き出し・読み込みができます。ブラウザのデータを消去したり機種変更したりすると学習進捗が失われるため、ときどきバックアップを書き出しておくことをおすすめします。

## PWAの更新について

このアプリはService Workerでオフライン対応しているため、コード側を更新した直後は**古いキャッシュがそのまま表示されることがあります**。ホーム画面のアイコンから開き直す、または一度アプリを完全に閉じてから再度開く（それでも変わらない場合はSafariの「履歴とWebサイトデータを消去」）と最新版に切り替わります。
